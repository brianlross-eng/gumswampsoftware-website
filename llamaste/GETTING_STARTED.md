# Llamaste Getting Started Guide

**Llamaste** is Gum Swamp Software's next-generation machine learning framework. Currently in active development, Llamaste provides a clean, intuitive API for building and training models.

## What is Llamaste?

Llamaste is designed to make machine learning approachable without sacrificing power. It offers:

- A clean, Pythonic API for defining and training models
- Intuitive abstractions for common ML workflows
- A focus on developer experience without compromising performance
- Support for modern ML patterns and practices

## Project Status

**Status:** Not Ready for Release

Llamaste is in active development. While the core framework is taking shape, the public API is still evolving. Expect breaking changes as the project matures toward its first release.
